## The entry

> WARNING: Do not meet yourself. If you do, do not wave. The warranty covers one timeline, and you are not in it.

111 characters, one line — a genuine-looking safety notice that turns the
real hazard of time travel (meeting your duplicate self) into the joke, and
saves the surprise for the last few words.

## Run it

```sh
node main.ts
```

It writes the label to `/output/entry.txt` (or `$OUTPUT_DIR/entry.txt` when
set). The file holds exactly the label above: 111 characters, one line, no
trailing newline.
